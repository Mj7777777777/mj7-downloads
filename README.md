## Installer

**Windows**
1. Fermez votre logiciel de musique, puis double-cliquez sur le fichier `.exe` téléchargé.
2. Si Windows affiche « Windows a protégé votre ordinateur » : cliquez sur **Informations complémentaires**, puis **Exécuter quand même**.
3. Suivez l'installation, puis faites rechercher les plugins dans votre logiciel
   (FL Studio : *Options > Manage plugins > Find installed plugins*).

**Mac** (Apple Silicon et Intel)
1. Fermez votre logiciel de musique, puis double-cliquez sur le fichier `.pkg` téléchargé.
2. Si le Mac refuse de l'ouvrir : ouvrez **Réglages Système > Confidentialité et sécurité**, descendez et cliquez sur **Ouvrir quand même**
   (ou faites clic droit sur le fichier > **Ouvrir**).
3. Suivez l'installation, puis faites rechercher les plugins dans votre logiciel
   (Ableton : *Settings > Plug-Ins*, cochez *Use Audio Units v2* et *Use VST3 Plug-in System Folders*, puis *Rescan*).

## Licence

Chaque plugin fonctionne **14 jours sans aucune limite**. Ensuite, le son est coupé 3 secondes toutes les 45 secondes
jusqu'à l'activation d'une clé de licence.

Pour activer : ouvrez le plugin, cliquez sur la petite ligne dorée sous son nom (« ESSAI … ACTIVER »),
collez votre clé et cliquez sur **COLLER ET ACTIVER**. Une clé « Suite » débloque tous les plugins MJ7 d'un coup,
sans connexion internet.

Pour acheter une licence, contactez MJ7.
